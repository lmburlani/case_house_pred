# Previsão de Preços de Imóveis

Este é o meu primeiro projeto de machine learning, desenvolvido originalmente para o processo seletivo do Grupo Uau, que estou revisitando para aplicar as abordagens que utilizo hoje. 

O objetivo central é prever o preço de imóveis com base em características como tamanho, número de quartos, banheiros, andares, entre outros. Nesta revisão, apliquei um tratamento de dados mais enxuto, regressão linear com alvo em log, validação cruzada (K-Fold).

## Arquivos do projeto

- `house_price_prediction.ipynb` — notebook com toda a análise e modelagem atualizada
- `house_sales.csv` — dataset com os dados dos imóveis (modificado)

## Tecnologias usadas

- Python
- Pandas / NumPy
- Scikit-learn
- Matplotlib / Seaborn
