# Previsão de Preços de Imóveis

Este é o meu primeiro projeto de machine learning, desenvolvido originalmente para o processo seletivo do Grupo Uau, que estou revitalizando, preservando a lógica e o contexto originais.

O objetivo é prever o preço de imóveis com base em características como área, número de quartos, banheiros, andares, entre outras. Nesta revisão, modernizei a implementação com um pipeline de tratamento de dados mais enxuto, regressão linear utilizando transformação logarítmica no alvo e validação cruzada com K-Fold.

## Arquivos do projeto

- `house_price_prediction.ipynb` — notebook com toda a análise e modelagem atualizadas
- `house_sales.csv` — conjunto de dados dos imóveis (adaptado para o projeto)

## Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
